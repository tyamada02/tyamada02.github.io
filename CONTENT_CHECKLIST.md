# Content Checklist

Use this checklist before writing the first version of the site.

## Identity

- public name to display
- name spelling in English
- affiliation
- department / institute / lab
- current position or title

## Public profile

- short self-introduction
- research fields
- keywords for search visibility
- academic background to include
- positions to include

## Research content

- major research topics
- current projects that are already public
- project summaries that can be written for a general academic audience
- software, datasets, or repositories to link

## Outputs

- journal papers
- conference papers
- preprints that are intentionally public
- talks / invited talks
- awards / grants / honors
- thesis information, if relevant

## External links

- institutional profile
- ORCID
- Google Scholar
- ResearchGate, only if intentionally used
- GitHub

## Files

- CV PDF
- selected publications PDF, only when copyright allows
- profile photo
- if CV is not ready, prepare a temporary page without a broken or dummy link

## Contact policy

- professional email address
- whether to list office address
- whether to list office phone number
- whether to use a contact form
- initial default: affiliation email only
- if contact details are not ready, use a temporary page with a short notice instead of a dead link

## Exclude by default

- personal address
- private phone number
- private email
- unpublished work
- internal draft notes
- collaborator or student private details

## Design decisions

- language: English first, with selective Japanese for key identity fields
- tone: formal / minimal / slightly personal
- whether to show news on the top page
- whether to prioritize publications or research overview on the top page
